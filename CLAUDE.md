# CLAUDE.md — Self Education App

## Project Overview

A self-education application with three core learning tracks:

1. **Python** — Programming fundamentals, advanced concepts, and practical projects
2. **Claude** — Working with Claude API, prompt engineering, and building AI-powered tools
3. **Japanese Language** — Vocabulary, grammar, kanji, and reading comprehension

## Tech Stack

- **Language**: Python 3.11+
- **AI**: Claude API (Anthropic SDK)
- Additional tooling and frameworks TBD

## Development Conventions

- Python code follows **PEP 8** style
- Use **type hints** for function signatures
- Write **docstrings** for public functions and classes
- Keep modules focused and small
- Use `pytest` for testing
- Commit messages should be clear and descriptive

## Learning Tracks
