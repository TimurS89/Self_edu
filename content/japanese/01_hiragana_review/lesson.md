# Hiragana Review: The Foundation

## Why Review Hiragana?

Even if you already know hiragana, instant recognition is essential. You should be able to read each character as fast as you read English letters. This lesson reviews all 46 basic hiragana.

## The Five Vowels (母音 / ぼいん)

| Hiragana | Romaji | Notes |
|----------|--------|-------|
| あ | a | Like "ah" in "father" |
| い | i | Like "ee" in "feet" |
| う | u | Like "oo" in "food" (lips unrounded) |
| え | e | Like "e" in "get" |
| お | o | Like "o" in "go" |

These vowels are the building blocks. Every hiragana character ends with one of these sounds (except ん).

## Common Confusion Pairs

Watch out for these similar-looking characters:
- **さ** (sa) vs **き** (ki)
- **は** (ha) vs **ほ** (ho)
- **ね** (ne) vs **れ** (re)
- **る** (ru) vs **ろ** (ro)
- **め** (me) vs **ぬ** (nu)

## Practice Tip

Speed is the goal. When reviewing the flashcards, try to answer within 2-3 seconds. If you need more time, rate the card as "Hard" or "Again" so it comes back sooner.
